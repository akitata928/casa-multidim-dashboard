專案目標

將原始 Excel VBA CASA 存款行為模型擴充為支援多維度批次執行， 並建立 Python 管線與 Streamlit Dashboard，且必須滿足銀行模型治理要求： 結果可回溯、可驗證、可比對 VBA 與 Python 一致性。
